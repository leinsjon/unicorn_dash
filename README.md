# Unicorn Dash 🦄

A road-crossing game for little kids, made for iPad. Help Sparkle the unicorn hop across the road without getting hit by cars, trucks, or horse-drawn carriages.

- **Controls:** drag the unicorn (or anywhere on the screen) up, down, left, or right to hop. Arrow keys work on a computer.
- **Difficulty:** Easy (slow cars), Medium, Hard (fast and busy).
- **Places:** Meadow, Candy, Snowy, Night, Beach.

It's one static `index.html` with no build step and no dependencies.

## Deploy on Render

New → Static Site → pick this repo. Leave **Build Command** empty and set **Publish Directory** to `.`

## Tip for iPad

Open the site in Safari, tap Share, then **Add to Home Screen**. It launches full screen like an app.
